Glass vs plastic: what actually separates the two materials, and which classification model to trust

A study of algorithms for discriminating glass from plastic, with honest measurement: every number published here was produced by the code in this repository — on a synthetic proxy task and on a real public dataset (TrashNet, glass and plastic classes, the authors' official split).

The three measured findings

  • What the input contains moves the number more than which model you pick. A model that sees only a thin 3% strip of studio backdrop — no object pixels at all — reaches 0.80 balanced accuracy, versus 0.88–0.94 for full frames. On this benchmark a large part of a published "glass vs plastic" accuracy is the room, not the material.
  • Whether a model leans on that backdrop is architecture-specific — so measure it. Cropping the backdrop away costs ResNet-18 6.2 points and nearly triples its glass-passed-as-plastic rate (7.3% → 18.3%), while MobileNetV3-Large and EfficientNet-B0 barely move. "Fine-tuned CNN" does not predict behaviour.
  • Cost separates the backbones that accuracy does not. MobileNetV3-Large reaches the top score with 4.2M parameters, 0.11G MACs and 8.6 ms/image — 12× fewer MACs than ResNet-18 for the same accuracy.
